# shpricefix

Fix SkyHanni's profit tracker showing the old npc sell price (?) for the one & quantum bundle, and 0 for unfanged parts.

**One IV Bundles**: uses bz price based off your skyhanni settings (buy order/instasell)

**Fang**: uses lbin data for dentist relic

> Requires SkyHanni, tested & works on version 9.1.0 (MC 26.1)

## Download

Head to [Actions](https://github.com/cd043136/shpricefix/actions) tab, click on the latest build (should be the top), scroll to the bottom and download the jar file for your mc version
